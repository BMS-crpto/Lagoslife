# Lagos Life Online v0.4
Run locally:  node server.js   then open http://localhost:3000
Online: upload this folder to a Node host (Render / Railway), start command `node server.js`.
Friends open the link, type the SAME room code, pick a role, play. No npm packages needed.

v0.4 adds: Lagos theme (₦ naira, 🚌 Danfo role, 🍲 Mama Put food menu, 🎉 Quilox Club for vibes, 💡 NEPA blackouts that make shop robbery pay more).
v0.3 added: 📦 Courier job (pick up at shop, deliver to a house), ⚡ energy (buy 🍔 food at shops), day/night cycle, random rain.

Controls: joystick = walk / drive (up gas, down brake, left-right steer). Drag screen = turn camera.
Green button = drive / exit car / buy house. Red ACTION = your job.
